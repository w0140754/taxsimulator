# Rookie’s Tax Sim — Public Build 2

This folder contains the public classroom build of **Rookie’s Tax Sim**.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the branch containing `index.html` and the `/ (root)` folder.
5. Save and use the Pages link GitHub provides.

The public `index.html` is intentionally bundled so the working source is not casually editable. It is not intended as security or DRM.
